# YouTube transcripts

[FlashData](https://flashdata.dev) · [API documentation](https://flashdata.dev/docs/sources/youtube_transcript)

Read an existing automatic caption track by default. Output includes `segments` with second-based `start` and `end`, `fullText`, and track metadata. This endpoint does not transcribe missing tracks.

## Example

```javascript
import { FlashData } from '@flashdata-dev/sdk';

const client = new FlashData({ apiKey: process.env.FLASHDATA_API_KEY });
const response = await client.youtube.transcript({
  video_id: 'dQw4w9WgXcQ',
  language: 'en',
  auto: false,
});
for (const track of response.results) {
  console.log(track.languageCode, track.isAutoGenerated);
  for (const segment of (track.segments ?? []).slice(0, 3))
    console.log(segment.start, segment.end, segment.text);
}
```

Run `node examples/youtube_transcript.mjs dQw4w9WgXcQ --output artifacts/youtube_transcript.json` from the checkout. Use `--help` for options. The command consumes credits.

## Parameters

`video_id` is required. Source options are properties on the first input object, or entries in `params` when using `queries`. Helpers default to realtime; pass `{mode: 'async'}` as the second argument for background work. Request options also accept `timeoutMs` and `signal`.

JSON is the default. Pass `{ accept: 'text/plain' }` in the second argument for text.
Realtime results also support `{ respondWith: 'markdown' }`. For background work,
choose Markdown when reading the completed result. See [response formats](../response-formats.md).

| Option     | Type / constraints                     | Default              |
| ---------- | -------------------------------------- | -------------------- |
| `language` | string or array of 1–10 distinct codes | `en-orig`, then `en` |
| `auto`     | boolean                                | true                 |

Omit `language` to prefer `en-orig`, falling back to `en` and returning one track.
A string such as `"en"` selects that exact language and keeps the single-track response.
An array of 1–10 distinct codes, including a one-element array, returns `tracks` and
`errors` inside each result. Each code must match `[A-Za-z0-9-]{1,35}`.

Read successful tracks even when another language fails. Each error includes
`languageCode`, `code` (`language_unavailable` or `retrieval_failed`) and `message`.
Both lists preserve request order; if all requested languages fail, `tracks` is empty.
Video-level extraction failures still fail the request. Explicit languages never fall
back to other languages. `auto` selects one caption source for the whole request:
`true` for automatic captions, `false` for uploaded captions. It defaults to `true`
for transcripts and `false` for captions, with no switch between the two.

## Multiple languages

```javascript
import { FlashData } from '@flashdata-dev/sdk';

const client = new FlashData({ apiKey: process.env.FLASHDATA_API_KEY });
const response = await client.youtube.transcript({
  video_id: 'aircAruvnKk',
  language: ['en', 'es'],
});
for (const result of response.results) {
  for (const track of result.tracks ?? []) console.log(track.languageCode, track.fullText);
  for (const error of result.errors ?? [])
    console.log(error.languageCode, error.code, error.message);
}
```

The same language array works with realtime, async, batch and bulk requests.
