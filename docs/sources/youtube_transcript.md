# YouTube transcripts

[FlashData](https://flashdata.dev) · [API documentation](https://flashdata.dev/docs/sources/youtube_transcript)

Read an existing automatic caption track by default. Output includes `segments` with second-based `start` and `end`, `fullText`, and track metadata. This endpoint does not transcribe missing tracks.

## Example

```javascript
import { FlashData } from '@flashdata-dev/sdk';

const client = new FlashData({ apiKey: process.env.FLASHDATA_API_KEY });
const response = await client.youtube.transcript({
  video_id: 'dQw4w9WgXcQ',
  language: 'en',
  auto: false,
});
for (const track of response.results) {
  console.log(track.languageCode, track.isAutoGenerated);
  for (const segment of (track.segments ?? []).slice(0, 3))
    console.log(segment.start, segment.end, segment.text);
}
```

Run `node examples/youtube_transcript.mjs dQw4w9WgXcQ --output artifacts/youtube_transcript.json` from the checkout. Use `--help` for options. The command consumes credits.

## Parameters

`video_id` is required. Source options are properties on the first input object, or entries in `params` when using `queries`. Helpers default to realtime; pass `{mode: 'async'}` as the second argument for background work. Request options also accept `timeoutMs` and `signal`.

| Option     | Type / constraints                | Default |
| ---------- | --------------------------------- | ------- |
| `language` | string; pattern `^[A-Za-z0-9-]+$` | "en"    |
| `auto`     | boolean                           | true    |

`auto` defaults to `true` for transcripts and `false` for captions. The example selects an uploaded English track explicitly, so it can be run on the same video as the captions example. Language selection has no automatic translation or fallback.
